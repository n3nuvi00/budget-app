# Budget App

Simple budget app for students to track income and expenses.

## 👥 Team

* Person 1: Home page (overview, balance, latest transactions)
* Person 2: AddExpense page (form to add income/expenses)

## 🚀 How to run

Run the following commands in terminal:

1. Clone repository:
   git clone https://github.com/n3nuvi00/budget-app.git

2. Go to project folder:
   cd budget-app

3. Install dependencies:
   npm install

4. Start app:
   npm run dev

5. Open in browser
